# 📱 PCGuardian iOS 版 —— iPhone / iPad 安装与使用

与 Windows 版完全同源：同一份 Gist 数据、同一套规则（打卡检查 / 倒计时 / **当天一次机会** /
家长临时解锁 / 后台改时长即时生效）。

## ⚠️ 先了解 iOS 的边界（和 PC 版的本质差异）

苹果不允许任何第三方 App 锁键盘、强制关机、盖住其他 App（Windows 那套在 iOS 上不存在）。
iOS 的正确做法是苹果官方的**「引导式访问」**：把设备钉死在本 App 里，退出需要家长密码。
本 App 负责里面的一切逻辑，引导式访问负责"出不去"，两者配合实现整机管控。

## 安装（无需 Mac，用 Windows 电脑 + 数据线）

1. **下载 ipa**：浏览器打开 https://github.com/kevinxuk/chore-reward-app/actions
   → 点最新的「Build PCGuardian iOS」→ Artifacts → 下载 `PCGuardian-iOS-ipa`（zip 解压出 .ipa）；
2. **电脑装 Sideloadly**：https://sideloadly.io （首次使用需同时安装 Apple 官网的
   iTunes + iCloud for Windows 驱动）；
3. iPhone/iPad 用数据线连电脑 → 打开 Sideloadly → 拖入 ipa → 填你自己的
   **Apple ID** → Start；设备上同意信任（设置 → 通用 → VPN与设备管理 → 信任开发者）；
4. 完成后设备桌面出现 **PCGuardian** 图标。

> **有效期说明**：免费 Apple ID 签名 **7 天有效**，到期黑屏闪退 → 数据线再签一次即可
> （每天用的话约每周 5 分钟）。**99 美元/年**开发者账号签名有效期 1 年，
> 也可以走 TestFlight 安装（免连线）。首次安装若提示"不受信任的开发者"，按第 3 步信任。

## 开启整机管控（关键一步，家长操作）

在孩子的 iPhone/iPad 上（一次性设置）：

1. 设置 → 辅助功能 → 引导式访问 → 打开，并设置**密码**（孩子不知道的那个）；
2. 可选：同一页里打开「辅助功能快捷键」（连按三次电源键/Home键开关）；
3. 打开 **PCGuardian** App → 连按三次 电源键(或Home键) → 右上角「开始」；
   —— 从此设备被钉在本 App 里：回家手势、切换 App 全部失效，只有输入家长密码才能退出。

日常节奏：孩子开机拿设备 → 被钉在锁定页「请先完成任务」→ 家长在网页后台给
阅读+背单词打勾 → 10 秒内 App 自动变绿解锁 → 孩子用内嵌浏览器上网/看内容，
顶部居中悬浮倒计时 → 时间到自动变回锁定页（当天不再发放）→ 交给家长或等到明天。

## 与 Windows 版的差异

| 功能 | Windows exe | iOS App |
|---|---|---|
| 锁键盘/盖住全屏 | 程序自身实现 | 依赖**引导式访问**（家长开启） |
| 到时强制关机 | shutdown /s | 无此概念：App 锁回「时间已用完」页，引导式访问保证出不去 |
| 防杀进程 | 看门狗+会话文件+进程伪装 | iOS 沙盒天然防篡改（杀不了进程、碰不到数据） |
| 改时长/临时解锁/当天一次机会 | ✔ | ✔（同一份 Gist，实时同步） |
| 解锁后可玩什么 | 整台电脑 | 本 App 内嵌浏览器（网页游戏/视频）；想要"自由玩"→ 家长输密码退出引导式访问 |

## 常见问题

- **倒计时会因切后台/锁屏暂停吗？** 不会。按时间戳计算，重新打开照样扣时。
- **孩子改系统日期刷时间？** 设置 → 屏幕使用时间 → 关闭「更改日期与时间」权限即可。
- **换 Gist / 改必做任务？** 需要改代码重新构建（ios/Sources/GuardianModel.swift 顶部常量）。
- **免费签名过期闪退？** 重新用 Sideloadly 签一次（数据不受影响，存在设备沙盒里）。
