# 🖥️ PC Guardian —— 儿童电脑使用时间管控（exe 版）

与 [家长后台](https://kevinxuk.github.io/chore-reward-app/) 打卡联动：
孩子开机后电脑自动锁定；**语文/英语阅读**和**背单词/古诗词**是每日使用电脑的前提（家长打卡或 AI 评分通过均可满足），电脑时长**全部来自家长「🖥️ 电脑任务」**（普通任务打卡奖励 / AI 评分奖励 / 零花钱自助兑换），孩子勾选后点「▶ 开始使用」主动开始。
倒计时结束自动锁定并强制关机。家长在网页后台控制时长，1 分钟内生效。

**exe 版无需在孩子电脑上安装 Python**，整个文件夹拷过去就能用。

## 🆕 任务分派 · 奖励电脑时间（v2 新增）

家长在网页后台点「🖥️ 电脑任务」（右上角为「🛠️ 临时解锁」开关，即点即存；含 💰 零花钱自助兑换设置）发布**额外任务**（如"完成数学口算一页"）并设定奖励分钟数：

- **不产生零花钱**：分派任务与奖金体系完全隔离，只奖励电脑时长；
- 孩子电脑**锁定页**会列出全部分派任务和各自的奖励时长；
- 家长给任务打卡后，该奖励进入孩子电脑的「🎁 可用的奖励时间」钱包，**跨天累计**；
- 孩子可**勾选多项**奖励（时长累加，单次上限默认 480 分钟，`reward_max_minutes` 可调），
  点「▶ 开始使用」开始倒计时——**点击那一刻即从钱包扣除**（防杀进程重复领取）；
- 奖励轮与基础轮（阅读/背单词）**互相独立**：奖励轮不占用"当天一次机会"，也不看基础打卡状态；
- 倒计时结束：还有其他奖励 → 回到锁定页继续选择（**不关机**）；没有奖励 → 与原来一样锁定+关机；
- 中途重启/杀进程：恢复剩余时间，不重不发；"躲避关机"判定与基础轮一致（2 小时内补关机）；
- 家长「撤销完成」会收回该任务**未使用**的奖励；「删除任务」同样使其未使用的奖励失效；
  已开始使用的奖励不退回（家长临时解锁接管时也是）。

> 已用状态（`guardian.spent.json`）只存孩子电脑本机（同样有隐藏影子副本防删）——孩子端
> 只读 Gist、没有任何凭据，这是防止孩子改数据的关键设计；家长端看不到"已用/未用"，
> 需要时看孩子电脑的 `guardian.log`（每次使用都有记录）。


## 🔄 自动升级

儿童端每 6 小时（以及每次开机启动约 90 秒后）自动检测 GitHub 上 `pcguardian/version.json`
的版本清单，发现有新版本就自动下载（sha256 校验）并安装重启，全程无需人工干预。

- 家长发布更新：改完 `guardian.pyw` / `PCVoiceScore.pyw` 后，在仓库 `pcguardian/` 目录运行
  `python make_manifest.py`（可带版本号），连同 `version.json` 一起提交推送即可；
- exe 主程序更新走 GitHub Release（`gh release create` 上传新 exe，清单会记录 sha256）；
- 安装时机：锁定页状态下自动安装并重启（锁定页闪一下即恢复）；孩子使用中不打扰，
  等回到锁定页再装；
- 已打开但未录音的评分尝试不计次数；文件均经 sha256 校验，防损坏防篡改；
- 局域网联调：`guardian.local.json` 里 `"update_base": "http://127.0.0.1:8123/pcguardian"`
  可让联调儿童端从局域网服务器取更新。

## ⭐ 必须完成任务（可配置）

「🖥️ 电脑任务」抽屉里有「⭐ 必须完成任务」设置：默认勾选**课外阅读、背单词/古诗词**
（主打卡表里的任务，可增删勾选）。孩子必须先完成这些必做任务（家长在主打卡表打卡），
才能勾选奖励时间「开始使用」电脑；清空勾选则电脑时长不受必做限制。
电脑任务（分派/AI 评分）与主打卡表完全独立，互不替代。

## 💰 零花钱自助兑换电脑时长（锁定页）

家长在网页后台「🖥️ 电脑时长」里开启「零花钱自助兑换」，设置**每日兑换上限（元）**与
**兑换价（元/小时，与周末游戏时间兑换同价）**后，孩子锁定页出现兑换面板：

- 显示：`💰 我的零花钱 ¥45.00 · 今日还可兑换 ¥10.00（兑换价 ¥5.00/小时）`
  ——余额口径与家长端一致（全部打卡收入 − 全部消费），再减去本机已兑换金额；
- 提供 30/60/90/120 分钟四档，点一下变「确认兑换？」**再点一下才扣钱**（两步确认防误触，
  6 秒不确认自动取消）；余额不足或超每日上限会拒绝并提示原因；
- 兑换成功 → 时长进入「🎁 可用的奖励时间」钱包，勾选使用（与奖励时间同一机制）；
- **消费记在孩子电脑本机**（`guardian.redeem.json` 双隐藏副本防篡改，云端只读不动——
  这是孩子端无凭据架构的要求）；家长端余额/消费列表**不含**这部分，对账时看孩子电脑
  `guardian.log` 里的 `[redeem]` 记录即可，每笔都有金额、时长和兑换前后余额。

## 🎤 AI 评分任务（朗读 / 单词背诵）

家长在网页后台「🖥️ 电脑任务」发布 **AI 评分任务**（孩子电脑上需配一次麦克风）：

1. **发布**：任务类型选「📖 朗读评分」或「🔤 单词背诵」；设**通过分数线**（默认 80）与奖励分钟数。
   材料两种来源：**粘贴**自己的文章/词表，或 **✨AI 按年级生成**——朗读短文可限定字数与段落数；勾选「古诗词」时 AI 只生成**课本真实古诗**（如三年级《山行》《望天门山》《咏柳》，按年级选篇，严禁编造），
   单词按九年义务教育该年级必须掌握的词表生成（年级可选，生成后可手动修改再发布）。
   电脑任务与主打卡表**完全独立**：完成（AI 评分通过或家长打卡）即自动获得奖励时间。
2. **AI 设置**（首次一次）：顶栏「🤖 AI设置」填 OpenAI 兼容接口的 endpoint / API key /
   语音识别模型 / 对话模型，「保存到云端」——密钥存**独立的 AI Gist**（不进打卡数据与
   导出备份；建议使用设了消费上限的专用 key）。孩子的语音会上传到所选服务商。
   **本地联调环境**：保存/测试连接自动走局域网服务器（配置存 `localtest/ai-config.json`，
   无需 GitHub token，支持本地大模型如 Ollama）。
   语音识别模型 / 对话模型，「保存到云端」——密钥存**独立的 AI Gist**（不进打卡数据与
   导出备份；建议使用设了消费上限的专用 key）。孩子的语音会上传到所选服务商。
3. **孩子侧**：锁定页出现「🎤 AI 评分任务」，点「🎤 开始任务」后**评分界面直接在锁定页同一个窗口内打开**（不开新窗口），评分结束自动回到锁定页：
   - 朗读：自动分段（40~80字/段）逐段朗读，**每段读完立即出分**（本段得分+准确/流利分项，
     屏幕常驻评分标准）；**逐段达标门禁**：某段未达标可当场重读一次，重读达标继续下一段，
     仍未达标则**提前结束**（不再读后续段），按已读内容打分（完整度扣减，通常不通过）；
     全部段落达标后出总分；
   - 单词：**乱序逐词**，每词 2 次（第2次显示音标 + 🔊 听发音按钮，点击用**小米 MiMo TTS** 朗读，
     接口失败自动回退 Windows SAPI；同一单词的发音本地缓存不重复计费；
     录音期间 🔊 自动禁用、开始录音时掐掉未播完的声音——防把发音录进识别造成串音），精确=100 分、音标结构对齐评分
     （θ/s、l/r 等混淆对给半分）；**常驻记分板**实时显示每个词的得分与均分进度；
   - **达到分数线才发放时间**：奖励分钟进钱包（可多选使用），或按绑定直接满足解锁条件；
     每任务每天默认 5 次尝试；家长手动打卡通道永远保留兜底。
4. **断网/接口故障**：评分程序会提示错误并退出，不影响锁定与家长打卡通道。
5. 评分结果只存孩子电脑（`guardian.aiscore.json` 双隐藏副本，防篡改）；家长想核对就看
   孩子电脑的 `guardian.log`（每次尝试与得分都有记录）。

孩子电脑运行评分程序需要（一次性）：
```
pip install pypinyin pronouncing
```
- **语音识别全部走云端**：小米 MiMo ASR（`https://api.xiaomimimo.com/v1`，
  model `mimo-v2.5-asr`，按任务语言自动传 zh/en），孩子电脑**无需下载任何模型**；
- 识别与对话（朗读+问答任务的出题/判题）都在家长端「🤖 AI设置」配置
  （endpoint 填 MiMo 地址，asrModel 填 `mimo-v2.5-asr`）；未配置识别接口时
  评分程序会明确提示；未配置对话模型时问答部分自动跳过；
- **单词发音（TTS）**：「🤖 AI设置」里选**发音角色**（mimo_default/冰糖/茉莉/苏打/白桦/
  Mia/Chloe/Milo/Dean，默认 mimo_default），或填**音色描述**用自然语言控制语速/语调/角色
  （如"语速偏慢、吐字清晰的温柔女声"，走 MiMo 音色设计模型 mimo-v2.5-tts-voicedesign，
  填了描述则以描述为准）。对应配置字段 `ttsVoice` / `ttsStyle`；
- 录音走系统 WinMM 无需额外库；`PCVoiceScore.pyw` 与本程序放同一目录；
- **🎤 麦克风试音**：运行 `PCGuardian.exe --mic-test`（或 `python guardian.pyw --mic-test`，
  锁定页右下角也有「🎤 试音」入口）——**输入设备（录音）与输出设备（回放）分别可选**，
  默认跟随 Windows 当前默认；3 秒试音带实时电平条、自动诊断音量/环境底噪、可回放确认；
  选择自动记住（存孩子电脑 `APPDATA\PCGuardian\audio.json`），识别"听不到孩子声音"先用它排查；
- **录音自动优化（默认开启，无需配置）**：送识别前自动剪掉首尾静音、低音量自动增益
  （按峰值自适应放大，小声读也能稳定识别）、纯噪声/呼吸声不送识别（防误判成单词）；
- **单词任务节奏**：开始录音后 2 秒内没有声音会自动结束并开始评估（不用点结束按钮）；
  朗读课文仍是说完后 1.5 秒自动结束。

## 📁 本地媒体文件夹（看视频 / 听音频 / 课外阅读单词）

家长把内容拷到孩子电脑 **程序目录下的 `media\` 文件夹**（默认 `<程序目录>\media\`，可在
`guardian.local.json` 用 `media_dir` 改成任意绝对路径），**按类型分文件夹存放**（子文件夹=合集，递归扫描）；
锁定页「📋 待完成的任务」为 **Tab 页切换**（📖 阅读 / 🔤 单词 / 📺 视频 / 🎧 音频，按钮带待办数量，
必做任务和普通打卡任务在任何 Tab 下都显示）：

```
media\
  ├─ 阅读\   .md 朗读材料（AI 评分，**按字数计奖：每 250 字 = 10 分钟**，保底 10 分钟）
  ├─ 单词\   .md 单词表（AI 评分，**按行数计奖：每行 0.5 分钟**，多行汇总）
  ├─ 视频\   MP4/AVI/MKV/MOV/WEBM/WMV（**按时长计奖：总时长 ÷ 2**，保底 1 分钟）
  ├─ 音频\   MP3/WAV/M4A/AAC/FLAC/OGG/WMA（**按时长计奖：总时长 ÷ 2**，保底 1 分钟）
  └─ 已完成\  完成的任务自动归档到这里（不再作为任务出现）
```

- **类型以文件夹为准**：放进「阅读」的内容一律按朗读任务处理（即使正文是单词行）；
  子文件夹 = 合集（如 `视频\纪录片蓝猫\01.mp4、02.mp4` → 连续播放，每集分别计奖）；
- 根目录散落文件/其他子文件夹按内容与扩展名自动归类（兼容旧结构）；
- 音视频内置播放（断点续播）；MP4/H.264 等自动用 cv2 逐帧在面板内直接播放；
  内置打不开的格式自动改用系统播放器（**防跳看**：累计观看不足视频时长无法领奖）；
- **MD 文档**：首行 = 标题（# 号可有可无），正文全英文单词行（3~60 行）→ 单词任务，否则朗读任务；
- **完成的任务自动归档**到「已完成」文件夹（保持子文件夹结构）——不再重复出现；
  想让孩子重做，把文件从「已完成」移回对应类型文件夹即可（位置变了=新任务）；
- `README.md` 不作为任务；`media_dir` 默认 `<程序目录>\media\`，可设绝对路径覆盖。

## ⏸ 奖励时间的暂停与继续

使用期间，顶部倒计时条下方有 **「⏸ 暂停并锁定」** 和 **「⏹ 结束退回」**：

- **暂停并锁定**：立即回锁屏，媒体同步暂停，**剩余时间完整保留（暂停期间不计时）**；
  锁定页按钮变为「▶ 继续上次使用（剩余 X 分钟）」，随时点击继续——支持重启、跨天；
- **结束退回**：剩余时间按整分钟退回钱包，以后想用随时再勾选；
- 护眼休息期间倒计时同样冻结，休息时间不扣。

## 工作原理

```
家长后台网页（index.html「🖥️ 电脑时长」）
        │ 打卡数据 + config.computer {minutes, unlock}
        ▼ 2 秒自动推送
GitHub Gist chore-data.json  ←—— 唯一数据源（已有，未改动结构）
        │ 只读 raw URL，免认证
        ▼ 轮询：锁定时每 10 秒（打卡后秒级解锁）· 解锁后每 60 秒
孩子电脑 PCGuardian.exe（PyInstaller 打包，单文件）
  锁定 = 无边框全屏置顶（隐藏任务栏）+ 键盘钩子，只留「关机」按钮
  解锁 = 主程序完全收起；屏幕【顶部居中】浮窗显示本次剩余时长（无法关闭）
  超时 = 重新锁定 → 10 秒提示 → shutdown /s /f 强制关机
```

## 防关闭设计（孩子关不掉）

| 孩子的尝试 | 结果 |
|---|---|
| 点 × / Alt+F4 关窗口 | 没有关闭按钮；解锁后主窗口完全收起，浮窗 Alt+F4 无效、被强杀 0.5 秒内自动重建 |
| Alt+Tab / Win 键切走 | 锁定期间键盘钩子全部吞掉，切不出去 |
| 任务管理器结束进程 | **看门狗**每 1 分钟检查一次，1 分钟内自动拉起；剩余时长**不重置**（会话文件恢复） |
| 杀掉进程躲关机 | 重启后发现倒计时已在死掉期间走完 → 立即锁定并**补执行关机** |
| 认出 pythonw.exe | 进程以 `sysguard.exe` 运行（exe 的伪装副本），任务管理器里不易辨认 |
| 改本地文件刷时间 | 会话文件隐藏 + 在 %LOCALAPPDATA%\PCGuardian 存隐藏影子副本，数值离谱视为无效 |
| **重启电脑/程序刷时间** | **每天只发放一次**：重启只恢复剩余时长，绝不重置；倒计时走完后 2 小时内重启视为躲避关机 → 立即补关机；超过 2 小时 → 锁定显示「今天已用完」，次日自动恢复 |
| 取消打卡再重新打卡 | 当天已发放过的时间不重置（想加时间请用「家长临时解锁」） |

> 家长自己怎么关：运行 `卸载-开机自启.bat`（移除自启+看门狗+结束进程），
> 或网页后台开「家长临时解锁」。Ctrl+Alt+Del 仍可用（系统级序列无法屏蔽）。

## 首次使用（3 步）

1. 把**整个文件夹**拷到孩子电脑（如 `C:\PCGuardian\`），双击 `安装-开机自启.bat`
   （用孩子的 Windows 账户运行一次）；
2. 重启电脑 → 自动全屏锁定，显示「请先完成任务」和两项任务清单；
3. 孩子完成阅读+背单词后，家长在「🖥️ 电脑任务」里**打勾**（或发布 AI 评分/普通任务）→
   孩子电脑 1 分钟内更新，孩子勾选时长点「▶ 开始使用」开始倒计时。

> 首次运行若弹出 **Windows SmartScreen** 蓝色警告（exe 未签名，正常现象）：
> 点「更多信息」→「仍要运行」。

## 家长控制（网页后台 → 🖥️ 电脑时长）

| 操作 | 效果 |
|---|---|
| 改时长（15~120 分钟或自定义） | 约 1 分钟内同步；**正在倒计时时改也会即时生效**（可延长可缩短） |
| 打开「家长临时解锁」 | 无倒计时直接解锁（给家长用电脑/奖励加时用），关闭后恢复管控，还能在关机倒数的 10 秒内救回一次 |
| 两项任务都打勾 | 成为「使用前提已满足」，孩子可勾选分派/兑换的时长使用；取消打勾 → 已解锁的这轮不受影响，但钱包会被禁用（提示先完成必做） |

> 注意：改时长/解锁需要云同步正常（后台顶栏 ☁️ 图标不是红色）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `PCGuardian.exe` | 主程序（双击=立即运行；`--demo`=真全屏测试，Esc 退出，不锁键盘不真关机） |
| `sysguard.exe` | 安装后生成：exe 的伪装副本，正式运行走它 |
| `watchdog.vbs` | 看门狗脚本（计划任务每分钟调用，进程被杀则自动拉起） |
| `guardian.local.json` | 本地配置（Gist 地址/轮询间隔/任务 id/关机倒计时等），可删，删了用内置默认值；`gist_url` 也可填本地 JSON 文件路径用于联调 |
| 无 | 锁定期间每 `poll_seconds_locked`(默认10) 秒检查一次打卡；解锁后每 `poll_seconds`(默认60) 秒刷新家长指令 |
| `guardian.session.json` | 运行时自动生成（隐藏）：记录基础轮当天已发放的时长，防重启刷时间，不用管它 |
| `guardian.reward.session.json` | 运行时自动生成（隐藏）：奖励轮倒计时的断点恢复，与基础轮分文件互不干扰 |
| `guardian.spent.json` | 运行时自动生成（隐藏）：奖励时间已用台账，防删除/重复领取 |
| `guardian.log` | 运行日志，排查问题先看它 |
| `安装-开机自启.bat` | 自启注册表 + 看门狗计划任务 + 生成 sysguard.exe |
| `卸载-开机自启.bat` | 一键全部移除（家长专用） |
| `guardian.pyw` | 源码（备用：exe 丢失时可按老办法用 Python 运行） |
| `localtest/` | 本地联调目录（见下节），不影响正式运行 |

## 📚 批量导入任务（.md/.txt 文件）

顶栏「📚 批量导入任务」可一次选择多个 .md/.txt 文件，**一个文件 = 一个任务**：
- 第一行 = 任务标题（支持 `#` markdown 标题，自动去掉 #）；
- 其余行 = 任务内容；空行分段（孩子端自动分段，古诗词保留版式）；
- 内容全是英文单词（每行一个、3~60 行）→ 自动建为「🔤 单词背诵」任务；
  否则建为「📖 朗读评分」任务（奖励默认 20 分钟）。

## 📨 成绩回执（家长端看孩子的 AI 打分）

AI 评分任务通过后，孩子电脑会把成绩**回执**（任务/得分/奖励分钟/日期）写进数据源同目录的
`chore-ai-results.json`（局域网联调）或上报到数据源服务器（`/api/airesult`）；家长端
「🖥️ 电脑任务」列表会自动显示：已通过的任务名变**绿色**，展示最后得分与获得的时间。
生产环境（GitHub Pages + Gist）下孩子端无写入通道，家长端暂无回执（后续可加受限写入或
Cloudflare Worker 转发）；孩子电脑 `guardian.log` 的 `[ai]` 记录始终可用。

## 🧪 本地联调（不碰 GitHub / Gist）

`localtest/` 目录是一套自包含的测试环境（`dry_run=true` 永不真关机）：

1. **家长端**：Chrome/Edge 打开 `index.html`（本地文件直接双击），点顶栏「🔗 绑定数据文件」
   选择 `C:\PCGuardian\localtest\chore-data.json`——之后发布任务/打卡都会实时写入该文件；
   （用本地 HTTP 方式测试则绑定按钮需要 http 源，直接 file:// 打开即可绑定）
2. **孩子端**：运行 `localtest` 里的 `python guardian.pyw --demo`（需装 Python；Esc 退出），
   它读的就是同一个 JSON 文件：发布→打卡→孩子端 3 秒内出现奖励→勾选→开始使用→台账扣除，
   全链路无需云端；
3. 联调数据在 `localtest/chore-data.json`，与真实 Gist 数据完全隔离；测试后可删掉
   `guardian.session.json / guardian.reward.session.json / guardian.spent.json` 复位钱包；
4. 自动化测试：`cd localtest` 后三选一（或全跑）：
   `python test_local.py`（55 项，钱包/台账/会话/防躲避关机等基础轮）、
   `python test_ai.py`（49 项，评分公式/朗读单词流程/MiMo 协议 mock E2E/guardian 集成）、
   `python test_update.py`（9 项，自动升级：下载/sha256 校验/换位/重启 bat，Popen 已伪化不会真重启）。

## 重新打包 exe（改了 guardian.pyw / PCVoiceScore.pyw 之后）

```
pip install pyinstaller
pyinstaller --noconfirm --onefile --noconsole --name PCGuardian ^
  --collect-all pypinyin --collect-all pronouncing --collect-all cmudict ^
  --collect-all cv2 --collect-all PIL --collect-all imageio_ffmpeg ^
  guardian.pyw
copy /y PCVoiceScore.pyw dist```
- 产物：`dist\PCGuardian.exe`（内含 cv2 逐帧播放器 / MiMo 音视频链路 / 护眼模式）+ 同目录的 `PCVoiceScore.pyw` 组件；
- **验收**：运行 `dist\PCGuardian.exe --selftest-voice`，显示
  `[selftest] OK lang=True phoneme=79 pinyin=True` 即打包成功；
- 发布包 = exe + PCVoiceScore.pyw + watchdog.vbs + 两个 bat + 说明文档
  （语音识别走 MiMo 云端，孩子电脑无需下载模型）；
- 依赖安装：`pip install pyinstaller pypinyin pronouncing cmudict cv2 PIL imageio_ffmpeg`。

## 常见问题

- **怎么救急解锁？** 网页后台开「家长临时解锁」（≤1 分钟生效）；或运行卸载 bat。
- **断网会怎样？** 保持锁定（更安全）或保持当前倒计时（更宽容），每分钟自动重试，恢复后照常联动。
- **杀毒软件报毒？** PyInstaller 单文件 exe 偶有误报，把 `C:\PCGuardian` 加入白名单即可。
- **换 GitHub/Gist？** 改 `guardian.local.json` 里的 `gist_url` 即可。
- **想给孩子当天加时间？** 网页后台开「家长临时解锁」（不限时），或临时解锁开启后再关闭——会重新开始一个完整倒计时轮次；也可以发布一个分派任务、完成后让孩子自己选用。
- **「躲避关机」判定多严？** 倒计时走完后 2 小时内重启电脑 → 补关机；2 小时后重启 → 锁定到明天（`expire_grace_seconds` 可调）。奖励轮同理；但"到点时还有其他奖励"的优雅结束不会触发补关机。
- **奖励时间和基础时长什么关系？** 完全独立的两本账：基础轮（阅读+背单词→固定时长）每天一次；奖励轮（分派任务）随时可选用、跨天累计，用一次扣一次。奖励轮解锁期间家长在后台改"本次时长"不会影响奖励倒计时（奖励时长在勾选时就固定了）。
- **为什么家长端看不到奖励"已用"？** 已用台账只存孩子电脑（孩子端只读云端、无凭据，防止孩子改数据）。想核对就看孩子电脑的 `guardian.log`，每次使用都有 `[reward]` 记录。
