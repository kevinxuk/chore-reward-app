# 🌟 家务零花钱打卡

孩子家务零花钱打卡表（2026年9月 v2）的单页网页版。无需安装、无外部依赖，打开即用。

**在线地址：<https://kevinxuk.github.io/chore-reward-app/>** · **儿童只读端：<https://kevinxuk.github.io/chore-reward-app/child.html>**

## 功能

- **每日打卡**：4 组 24 项任务（晨间 / 家务 / 学习 / 运动），单击即打卡，金额自动入账；
- **多视图**：日 / 周 / 月 / 年切换，PC 与平板默认网格视图，手机默认日视图，均可前后翻页浏览；
- **周末兑换**：仅周六/周日可用零花钱兑换游戏时间（默认 5 元/小时，支持自定义时长），还可添加任意自定义消费项，每笔可撤销；
- **自由金额**：周末家务（+1~3元）打卡时可自由设定本次所得金额；
- **收入统计**：每日收入、月结算（累计收入/最大单日/支出/结余）、年汇总一目了然；右上角「💰 总计」实时显示累计零花钱（消费自动减扣）；
- **本地存储**：数据实时保存在浏览器本地，可一键导出/导入 JSON 备份或换设备迁移。

## 🧒 儿童只读端（child.html）

卡通风格的「观看模式」页面，供孩子随时查看当天完成情况，**只能看、不能改**：

- ✅「我做完啦！」与 🌱「还没有完成哦」两列清单，含进度环、今日收获与翻日期浏览；
- **数据与本页完全同源**：同一浏览器打开时实时读取 `chore-app-data`（家长端一打卡，孩子端秒级刷新）；跨设备打开（可用配置链接 `child.html#token=…` 携带 token 或直接粘贴）则只读拉取同一个云端 Gist，绝不写回；
- 周末专属任务仅在周六/周日显示，口径与家长端一致；全部完成时页面放 🎉。

## 使用提示

- 数据存于浏览器 localStorage，**换浏览器/清缓存前请先导出 JSON 备份**；
- Chrome/Edge 桌面版可点「🔗 绑定数据文件」，将进度自动同步写入一个本地 JSON 文件。

## ☁️ 跨设备云同步（可选）

- 打开网页后点顶栏 ☁️ 完成绑定，之后：打开自动拉取最新数据，打卡/兑换 2 秒后自动推送；
- 两端同时改过数据时，会弹出对比框让你选择 合并 / 以本机为准 / 以云端为准；
- 新设备配置：打开"配置链接"（含一次性 token 片段）即自动启用，无需手动输入；
- 云存储为 GitHub 私有 Gist，token 仅存于各设备本机、不进入本仓库；token 有效期到期时 ☁️ 会变红，重新生成并在 ☁️ 设置里粘贴即可（无需改代码）；
- ⚠️ 若怀疑 token 泄露：到 GitHub 设置吊销重发，再生成新配置链接。
