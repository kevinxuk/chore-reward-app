# 家务零花钱打卡 - GitHub Pages 版

## 🚀 一键部署到 GitHub Pages

### 步骤 1: 创建 GitHub 仓库

1. 访问 https://github.com/new
2. 仓库名：`chore-reward-app`（或其他名称）
3. 选择 **Public**
4. 点击 **Create repository**

### 步骤 2: 上传文件

方法一：网页上传
1. 进入仓库 → Add file → Upload files
2. 将 `web_app/index.html` 拖入
3. 点击 Commit changes

方法二：命令行
```bash
cd C:\Users\Administrator\Documents\1mycode\daydayup\web_app
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/你的用户名/chore-reward-app.git
git branch -M main
git push -u origin main
```

### 步骤 3: 启用 GitHub Pages

1. 进入仓库 → **Settings** → **Pages**
2. Source 选择 `main` branch
3. Folder 选择 `/ (root)`
4. 点击 **Save**

### 步骤 4: 访问应用

等待 1-2 分钟后，访问：
```
https://你的用户名.github.io/chore-reward-app/
```

## 📱 使用方法

### 孩子端
1. 打开网页
2. 点击任务方框打勾/取消
3. 自动统计今日收入和本月累计

### 家长端
1. 点击右上角「家长端」
2. 输入密码（默认：`123456`）
3. 审核打卡记录
4. 查看历史记录表格
5. 导出 CSV 数据

## 🔒 数据说明

- 数据保存在浏览器 localStorage
- 同一设备不同浏览器数据不互通
- 清除浏览器数据会丢失记录
- 建议使用同一浏览器长期使用
